Offline speaker-diarization models

This release uses the FluidInference Core ML speaker-diarization asset set
consumed by FluidAudio v0.12.4 (pyannote segmentation, WeSpeaker embeddings,
and VBx clustering parameters).

Upstream: https://huggingface.co/FluidInference/speaker-diarization-coreml

Upstream source models include:
- pyannote/segmentation-3.0 (MIT)
- WeSpeaker speaker embeddings (verify upstream notices before redistribution)

The converted Core ML bundles are not the original training code. Ship this
notice with every distribution that includes the staged diarization assets.
