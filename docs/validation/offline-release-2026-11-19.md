# Scribe offline release validation

The local arm64 Release archive passed the offline compatibility smoke on
macOS 27.2.1 (26B131) with Xcode 27.2 (27B52). The tested copy was relocated
and passed strict Developer ID signature verification. Its code directory hash
and embedded binaries matched the archive. The
[provenance record](offline-release-2026-11-19.json) identifies the signed
build, model bytes, bundled helpers, and runtime settings.

## Compatibility smoke

The production downloader passed a clean install from the pinned upstream
revisions. The upgrade test copied the rollback pack and used local staged
bytes to simulate an interrupted encoder download and same-size corruption.
Retry fetched only the missing weights and the corrupted file. Both manifests
validated their corresponding assets after retry. The signed bundle's manifest
matched the source manifest used in both tests.

The shipping import, queue, review, and export code ran in a Release harness
with the actual signed worker and media helpers. A macOS process sandbox denied
network access, and a loopback bind failed with a permission error under that
profile. Model download occurred before the offline runs.

- The bundled media helpers probed and prepared stereo FLAC, MP4 with AAC, and
  each selected audio track in a two-track MKV. All produced 16 kHz mono
  16-bit PCM, and the two MKV tracks produced their expected distinct tones.
- A 7.746-second synthetic speech WAV passed folder import, automatic VBx,
  canonical transcript validation, review edit persistence, and TXT, SRT, and
  JSON export. Review reprocessing completed separate exact-one and up-to-two
  runs and retained the original edited revision.
- The production matcher automatically identified the synthetic speaker in
  the current run using a persisted 256-dimensional enrollment generated by
  the rollback app's bundled FluidAudio 0.17.4 worker. The enrollment used
  the same fixture speech, which tests compatibility of the saved embedding.
- The freshly installed pack produced 288 ordered, bounded ASR tokens and six
  bounded diarization intervals from 52.476 seconds of repeated synthetic
  speech. The worker reported chunked ASR and disk-backed diarization.
- Resident dictation warmed, transcribed the 7.746-second fixture, and unloaded
  with CTC ready and again with CTC absent. Each pass produced 48 ordered
  tokens bounded by the source duration.

## Settings for a quality baseline

Batch and dictation ASR, VBx Core ML segmentation, embedding, and rho use
`cpuAndNeuralEngine`. The WeSpeaker filterbank and CTC mel spectrogram use
`cpuOnly`. The optional CTC encoder uses `cpuAndNeuralEngine`. The worker
loads the compiled Silero model with the Core ML default configuration. These
settings describe configured compute units. Per-operation hardware placement
was outside this smoke.

The ASR model window is 14.96 seconds with 2 seconds of overlap. The runs used
automatic language selection and enabled speaker matching. VBx used nonexclusive
intervals, excluded overlap from embeddings, and applied the automatic,
exact-one, and up-to-two count controls. Its observed settings included a
0.6 clustering threshold, 0.1-second minimum gap, 1.0-second embedding duration
floor, 0.2 segmentation step ratio, and 20 maximum VBx iterations. The
provenance record preserves the full worker configuration and the fixture
hashes.

## Rollback and verification limits

The retained rollback pair is `build/rollback/Scribe-0.2611101145.0/Scribe.app`
with the sibling `Models` directory. Its CDHash is
`1a0fcccbcaa6806d9b16f67c8b3a8b339a0bd2a2`. It uses FluidAudio 0.17.4,
FFmpeg and FFprobe 7.1.1, and profile
`parakeet-v3-offline-diarization-v1` with `Encoder.mlmodelc`. The rollback
worker opened that pair and extracted the enrollment under the same network
denial. Both signed apps declare the same bundle version. Use the code
directory and manifest hashes to distinguish them. The in-app updater requires
a strictly newer candidate version.

The smoke covered app components through an isolated host harness. Native
Settings and review-window interactions, microphone capture, Accessibility
insertion, and existing personal speaker libraries remain unverified on the
signed candidate. The artifact is a local signed archive. Notarization,
Gatekeeper on a clean Mac, and the distribution update path were outside this
pass. Comparative WER, diarization scoring, and latency await the 12-speaker
reference sample.
